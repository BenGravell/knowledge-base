Analytical Differentiation on a Digital Computer

Topics include Symbolic differentiation, Analytic differentiation, Computer algebra, Automatic differentiation history, Derivatives.

Nolan's 1953 master's thesis is one of the earliest known works on using a digital computer to carry out analytical differentiation. It is historically important as a boundary object between later computer algebra systems and automatic differentiation, showing that derivative generation was already being framed as a programmable symbolic computation problem at the start of electronic computing.
