Control System Synthesis by Root Locus Method

Topics include Root locus, Feedback control, Control system synthesis, Classical control, Characteristic roots, Transient response, Frequency response.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Evans introduces the root locus method as a graphical design tool for tracking how the closed-loop poles of a feedback system move as gain varies. The paper helped make pole-location reasoning practical for classical control synthesis, linking transient response and frequency-response requirements to a single construction.

<!-- chunk {"id": "abstract-0003", "role": "abstract", "section": "Abstract", "weight": 2.0} -->

The root locus method determines all of the roots of the differential equation of a control system by a graphical plot which readily permits synthesis for desired transient response or frequency response.
