Matplotlib: A 2D Graphics Environment

Topics include Scientific plotting, Python, Visualization, Open-source software, Reproducible research, Data analysis.

Introduces Matplotlib as a Python plotting environment designed to combine publication-quality graphics with interactive scripting. The paper documents the design goals behind one of the core visualization tools in the scientific Python ecosystem.

Matplotlib is a 2D graphics package used for Python for application development, interactive scripting, and publication-quality image generation across user interfaces and operating systems.
