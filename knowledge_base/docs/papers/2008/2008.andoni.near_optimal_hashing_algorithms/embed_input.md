Near-optimal Hashing Algorithms for Approximate Nearest Neighbor in High Dimensions

Topics include Approximate nearest neighbors, Locality-sensitive hashing, High-dimensional search, Randomized algorithms, Data structures, Similarity search.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Develops near-optimal locality-sensitive hashing schemes for approximate nearest-neighbor search in high-dimensional Euclidean spaces. The work improved the theoretical query-time exponent and influenced later practical ANN data structures.

<!-- chunk {"id": "abstract-0003", "role": "abstract", "section": "Abstract", "weight": 2.0} -->

In this article, we give an overview of efficient algorithms for the approximate and exact nearest neighbor problem. The goal is to preprocess a dataset of objects (e.g., images) so that later, given a new query object, one can quickly return the dataset object that is most similar to the query. The problem is of significant interest in a wide variety of areas.
