Asymptotically Efficient Adaptive Allocation Rules

Topics include Multi-armed bandits, Lai-Robbins bound, Adaptive allocation, Upper confidence bounds, Regret lower bounds, Sequential experiments, Clinical trials.

Lai and Robbins derive asymptotically efficient adaptive allocation rules for parametric multi-armed bandit problems and establish the logarithmic regret lower-bound structure now called the Lai-Robbins bound. The paper is a cornerstone of bandit theory because it connects optimal exploration rates to information-theoretic distinguishability between arms.

Let Pi_j (j = 1,..., k) denote statistical populations (treatments, manufacturing processes, etc.) specified respectively by univariate density functions f(x; theta_j) with respect to some measure nu, where f(.;.) is known and the theta_j are unknown parameters belonging to some set Theta. Assume that integral from -infinity to infinity of |x|f(x; theta) dnu(x) < infinity for all theta in Theta. How should we sample x_1, x_2,... sequentially from the k populations in order to achieve the greatest possible expected value of the sum S_n = x_1 +... + x_n as n -> infinity? Starting with there has been a considerable literature on this subject, which is often called the multi-armed bandit problem. The name derives from an imagined slot machine with k >= 2 arms. (Ordinary slot machines with one arm are one-armed bandits, since in the long run they are as effective as human bandits in separating the victim from his money.)
