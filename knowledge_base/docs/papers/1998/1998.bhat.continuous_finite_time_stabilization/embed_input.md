Continuous Finite-time Stabilization of the Translational and Rotational Double Integrators

Topics include Finite-time stability, Double integrator, Nonlinear control, Lyapunov methods, Rotational dynamics, Bounded feedback.

Gives bounded continuous time-invariant feedback laws that stabilize translational and rotational double integrators in finite time. The paper is especially useful for separating finite-time convergence design from asymptotic stabilization and for handling rotational unwinding effects.

A class of bounded continuous time-invariant finite-time stabilizing feedback laws is given for the double integrator. Lyapunov theory is used to prove finite-time convergence. For the rotational double integrator, these controllers are modified to obtain finite-time-stabilizing feedback that avoid "unwinding".
