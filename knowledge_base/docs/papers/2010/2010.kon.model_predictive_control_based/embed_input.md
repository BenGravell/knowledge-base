Model Predictive Control Based on ARX Models

Topics include Model predictive control, ARX models, Process control, Disturbance rejection, Linear systems, Incremental models.

Proposes a linear MPC formulation based on incremental ARX models, including feedforward treatment for unmeasured disturbances. The contribution is a compact process-control method that connects data-driven linear models to standard constrained predictive control.

This study proposes linear model predictive control (MPC) based on ARX models in incremental form. Feedforward action for external disturbance can eliminate the effect of unmeasured disturbance, which is popular in process industries. Simulation example illustrates the robust performance of the proposed approach.
