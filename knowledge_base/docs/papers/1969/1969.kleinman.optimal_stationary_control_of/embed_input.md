Optimal Stationary Control of Linear Systems with Control-dependent Noise

Topics include Stochastic control, Control-dependent noise, Linear quadratic regulator, Multiplicative noise, State feedback, Optimal control, Feedback gains.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Kleinman studies optimal stationary control for linear systems whose driving noise intensity depends on the control input. The paper proves that the optimal controller is linear in the state and gives a convergent algorithm for computing the feedback gains, extending LQR-style synthesis to a control-dependent multiplicative-noise setting.

<!-- chunk {"id": "abstract-0003", "role": "abstract", "section": "Abstract", "weight": 2.0} -->

Optimal stochastic control is investigated for linear systems in which the intensity of the driving noise is proportional to control input. Conditions are given under which an optimal control always exists. It is shown that the optimal control is linear in the system state. A convergent algorithm is developed for computing the optimal feedback gains.
