A Dichromatic Framework for Balanced Trees

Topics include Red-black tree, Balanced trees, Dichromatic framework, Data structures, Search trees, Tree rebalancing, Concurrent updates.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Guibas and Sedgewick introduce the dichromatic framework that became the red-black tree abstraction for balanced binary search trees. The paper unifies earlier balanced-tree methods and develops one-pass update and rebalancing procedures, making red-black trees a durable practical data structure.

<!-- chunk {"id": "abstract-0003", "role": "abstract", "section": "Abstract", "weight": 2.0} -->

In this paper we present a uniform framework for the implementation and study of balanced tree algorithms. We show how to imbed in this framework the best known balanced tree techniques and then use the framework to develop new algorithms which perform the update and rebalancing in one pass, on the way down towards a leaf. We conclude with a study of performance issues and concurrent updating.
