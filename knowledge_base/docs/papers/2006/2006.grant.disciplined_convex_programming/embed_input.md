Disciplined Convex Programming

Topics include Disciplined convex programming, Convex optimization, Optimization modeling, Canonicalization, CVX, Expression grammars.

Defines disciplined convex programming as a grammar for constructing convex models that software can verify and transform automatically. The paper is the conceptual foundation for CVX-style modeling systems and later tools such as CVXPY.

A new methodology for constructing convex optimization models called disciplined convex programming is introduced. The methodology enforces a set of conventions upon the models constructed, in turn allowing much of the work required to analyze and solve the models to be automated.
