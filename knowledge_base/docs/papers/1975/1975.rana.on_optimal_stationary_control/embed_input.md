On Optimal Stationary Control of Systems with State Dependent Noise

Topics include Stochastic control, State-dependent noise, Linear quadratic regulator, Multiplicative noise, Stationary control, Existence criteria.

Rana and Mahalanabis refine existence criteria for optimal stationary linear-quadratic control of systems with state-dependent noise. The note sits in the line of multiplicative-noise LQR results, simplifying conditions under which an optimal stationary control law exists.

This note proposes a simplified existence criterion for the linear quadratic optimal control law for systems with state dependent noise.
