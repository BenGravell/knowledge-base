Multirotor Aerial Vehicles: Modeling, Estimation, and Control of Quadrotor

Topics include Quadrotor modeling, Multirotor vehicles, State estimation, Nonlinear control, Aerial robotics, Attitude control, Tutorial survey.

Provides a tutorial-style modeling, estimation, and control reference for multirotor vehicles, with the quadrotor as the central case. Its value is pedagogical: it organizes rigid-body dynamics, sensing, observer design, and feedback control into a coherent starting point for researchers building or analyzing small aerial robots.

This article provides a tutorial introduction to modeling, estimation, and control formultirotor aerial vehicles that includes the common four-rotor or quadrotor case.
