The MNIST Database of Handwritten Digit Images for Machine Learning Research [Best of the Web]

Topics include MNIST, Handwritten digits, Benchmark datasets, Image classification, Optical character recognition, Neural networks, Dataset curation.

Documents the MNIST handwritten-digit resource and explains why its fixed train/test split, normalized 28-by-28 images, and broad result table made it a durable benchmark for machine learning. The article is useful as a compact citation for MNIST itself rather than for a new model, highlighting both the dataset's convenience and the historical performance landscape around digit classification.

In this issue, “Best of the Web” presents the modified National Institute of Standards and Technology (MNIST) resources, consisting of a collection of handwritten digit images used extensively in optical character recognition and machine learning research.
