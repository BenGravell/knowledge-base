## Introduction

Figure 1: A trajectory ζx (red) that satisfies an STL task ϕ is obtained by expanding a tree of trajectories, using an RRT, from a given initial state x0. The tree of trajectories is expanded within the time-varying set ℬϕ(t) such trajectory evolving into ℬϕ(t) also satisfy the STL task ϕ.

The application of sampling-based planners to plan kino-dynamically feasible trajectories in complex environments for systems subject to spatio-temporal constraints has been an active area of research during the past decades \[(https://arxiv.org/html/2506.10739v1#bib.bib1), (https://arxiv.org/html/2506.10739v1#bib.bib2)\]. Particularly, with the aim of deploying autonomous systems with verifiable performance guarantees, a growing body of literature has been devoted toward designing planning algorithms to synthesize trajectories satisfying tasks expressed as Linear Temporal Logic (LTL) formulas \[(https://arxiv.org/html/2506.10739v1#bib.bib3), (https://arxiv.org/html/2506.10739v1#bib.bib4), (https://arxiv.org/html/2506.10739v1#bib.bib5), (https://arxiv.org/html/2506.10739v1#bib.bib6), (https://arxiv.org/html/2506.10739v1#bib.bib7)\] and, more recently, Signal Temporal Logic (STL) formulas \[(https://arxiv.org/html/2506.10739v1#bib.bib8), (https://arxiv.org/html/2506.10739v1#bib.bib9), (https://arxiv.org/html/2506.10739v1#bib.bib10), (https://arxiv.org/html/2506.10739v1#bib.bib11)\].

The focus of this work is on trajectory planning for linear systems under STL specification, leveraging Rapidly Exploring Random Trees (RRT) \[(https://arxiv.org/html/2506.10739v1#bib.bib12)\] and, in particular, its asymptotically optimal variant RRT^⋆^ \[(https://arxiv.org/html/2506.10739v1#bib.bib13)\], with applications to real-time robot motion planning in complex environments.

### Contributions

In this paper, we propose to adopt a novel approach to real-time sampling-based planning of trajectories for linear systems subject to STL constraints, leveraging the notion of forward invariance of time-varying sets. Namely, we formalize a simple, yet effective, approach to cast a STL specification, expressed over linear predicate functions, into a time-varying set, expressed as a time-varying polyhedron, which we design via linear programming. We show via a non-smooth analysis that the resulting set is forward invariant for the system dynamics, i.e., there exists a controller that maintains the system within the set under input constraints, given that the system starts within the set. While the problem of casting STL specifications into time-varying sets was previously considered in \[(https://arxiv.org/html/2506.10739v1#bib.bib14), (https://arxiv.org/html/2506.10739v1#bib.bib15), (https://arxiv.org/html/2506.10739v1#bib.bib16), (https://arxiv.org/html/2506.10739v1#bib.bib17), (https://arxiv.org/html/2506.10739v1#bib.bib18)\], our contribution differs from these previous works in the following terms. While \[(https://arxiv.org/html/2506.10739v1#bib.bib16), (https://arxiv.org/html/2506.10739v1#bib.bib17), (https://arxiv.org/html/2506.10739v1#bib.bib18)\] consider the entire STL fragment of specifications, their approach considers complex reachable set computations, which often can not be achieved in real-time. In this regard, we trade off a loss in expressivity, as we consider a subfragment of STL, for a reduction in computational complexity, for which we don't need to undertake complex reachable sets computations. On the other hand, compared to \[(https://arxiv.org/html/2506.10739v1#bib.bib14), (https://arxiv.org/html/2506.10739v1#bib.bib15)\], we here consider a more expressive STL fragment that includes nested temporal operators, thus allowing for a richer set of specifications, e.g., recurring tasks.

Specifically, we encode an STL task $\phi$ into a time-varying polyhedron $\mathcal{B}^{\phi}{(t)}$ (see. Fig (https://arxiv.org/html/2506.10739v1#S1.F1 "Figure 1 ‣ I Introduction ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")), we provide a real-time implementation of RRT^⋆^ to synthesize dynamically feasible trajectories satisfying the task $\phi$. Namely, if we let $\zeta_{x}{(t)}$ represent a trajectory of a given linear system, we then propose to expand a tree of sampled trajectory that evolves within the time-varying set $\mathcal{B}^{\phi}{(t)}$ from which we obtain a minimum cost trajectory satisfying $\phi$.

### Related work

The authors in \[(https://arxiv.org/html/2506.10739v1#bib.bib19), (https://arxiv.org/html/2506.10739v1#bib.bib20), (https://arxiv.org/html/2506.10739v1#bib.bib21), (https://arxiv.org/html/2506.10739v1#bib.bib22), (https://arxiv.org/html/2506.10739v1#bib.bib11)\] first explored the application of RRT^⋆^ to synthesize a feasible trajectory satisfying a given STL specification. Namely, \[(https://arxiv.org/html/2506.10739v1#bib.bib19), (https://arxiv.org/html/2506.10739v1#bib.bib21), (https://arxiv.org/html/2506.10739v1#bib.bib22)\] exploit the notion of STL robust semantics \[(https://arxiv.org/html/2506.10739v1#bib.bib23)\]---a metric functional defining the distance of a trajectory from the set of trajectories satisfying a given task $\phi$---to guide the synthesis of satisfying trajectories using RRT^⋆^. However, the dynamics of the system, as well as input limitations, are not directly considered therein, which are instead considered in the present work. A different approach is considered in \[(https://arxiv.org/html/2506.10739v1#bib.bib11)\], where an RRT algorithm is defined for a multi-agent system case. A recursive set of rules is defined to guide the expansion of the tree of sampled trajectories, avoiding the introduction of robust semantics, but the dynamics of the system are again not considered, whereas we consider controllable linear systems. On the other hand, \[(https://arxiv.org/html/2506.10739v1#bib.bib20)\] proposes an RRT^⋆^ algorithm that handles nonlinear dynamics with input limits and STL constraints via robust semantics, which are non-smooth and require recursive evaluations. We instead avoid recursive evaluation by casting STL tasks as time-varying sets offline. More in line with our approach are the works in \[(https://arxiv.org/html/2506.10739v1#bib.bib24), (https://arxiv.org/html/2506.10739v1#bib.bib25), (https://arxiv.org/html/2506.10739v1#bib.bib26)\] where Control Barrier Function (CBF) constraints are introduced within a sampling-based planner, but with the goal of synthesizing collision-free trajectories, rather than enforcing spatio-temporal constraints on them. Particularly in \[(https://arxiv.org/html/2506.10739v1#bib.bib26)\], Signal Temporal Logic constraints are considered by leveraging a Mixed-Integer Linear Programming (MILP) formulation \[(https://arxiv.org/html/2506.10739v1#bib.bib9)\], which is known to scale poorly over the state dimension and duration of the task.

While the fragment in ((https://arxiv.org/html/2506.10739v1#S2.E11 "In II-A Signal Temporal Logic ‣ II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")) does not capture the full expressivity of the STL fragment in ((https://arxiv.org/html/2506.10739v1#S2.E5 "In II-A Signal Temporal Logic ‣ II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")), we focus on ((https://arxiv.org/html/2506.10739v1#S2.E11 "In II-A Signal Temporal Logic ‣ II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")) for the following reasons. First, synthesizing trajectories that satisfy general STL specifications is an NP-hard problem, typically tackled using Mixed-Integer Linear Programming (MILP). Although MILP solvers are sound and complete, their computational demands are often prohibitive, even for formulas within the fragment ((https://arxiv.org/html/2506.10739v1#S2.E11 "In II-A Signal Temporal Logic ‣ II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")), making real-time planning infeasible. Regarding the absence of the negation operator in ((https://arxiv.org/html/2506.10739v1#S2.E11 "In II-A Signal Temporal Logic ‣ II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")) --- which is commonly used to enforce safety properties (e.g., "always avoid region $\mathcal{H}$") --- this limitation does not significantly reduce expressivity in our settings since safety requirements will be handled at the sampling level by rejecting trajectories entering unsafe regions of the workspace, e.g. obstacles. At the same time, we admittedly can handle the $\vee$ operator only at a high level of the formula such that formulas of type $F_{\lbrack a,b\rbrack}G_{\lbrack a^{\prime},b^{\prime}\rbrack}{({\mu^{h_{1}} \vee \mu^{h_{2}}})}$ are not within fragment ((https://arxiv.org/html/2506.10739v1#S2.E11 "In II-A Signal Temporal Logic ‣ II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")) and we leave this extension as future work.

To summarize, compared to planning via MILP solvers (e.g. \[(https://arxiv.org/html/2506.10739v1#bib.bib8)\]), we trade off a reduction in expressivity, for a simple and effective implementation that allows for real-time planning of trajectories satisfying STL tasks in the fragment ((https://arxiv.org/html/2506.10739v1#S2.E11 "In II-A Signal Temporal Logic ‣ II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")), from which a rich set of behaviors of common interest (e.g. rescue, exploration, and patrolling) can be obtained.

### II-B Viability and forward invariance of set-valued maps

As pointed out in the introduction, we propose to adopt a forward invariance perspective over the satisfaction of STL specifications from fragment ((https://arxiv.org/html/2506.10739v1#S2.E11 "In II-A Signal Temporal Logic ‣ II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")) on the same line of \[(https://arxiv.org/html/2506.10739v1#bib.bib32), (https://arxiv.org/html/2506.10739v1#bib.bib15)\]. Specifically, we consider encoding STL tasks from the fragment ((https://arxiv.org/html/2506.10739v1#S2.E11 "In II-A Signal Temporal Logic ‣ II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")) into a time-varying set derived as the level set of a non-smooth Control Barrier Function (CBF) \[(https://arxiv.org/html/2506.10739v1#bib.bib33)\] of the form ${\mathfrak{b}}:{{{\mathbb{R}}^{n} \times {\lbrack t_{0},t_{1}\rbrack}}\rightarrow{\mathbb{R}}}$, for some interval ${\lbrack t_{0},t_{1}\rbrack} \subset {\mathbb{R}}_{\geq 0}$, with level set $\mathcal{B}:{{\lbrack t_{0},t_{1}\rbrack}\rightarrow 2^{\mathbb{X}}}$ defined as

We consider the function $\mathfrak{b}$ to be Lipschitz continuous and concave on ${\mathbb{R}}^{n}$, while it is piece-wise linear on $\lbrack t_{0},t_{1}\rbrack$, with a finite sequence of discontinuities ${(s_{i})}_{i = 1}^{n_{s}}$ such that $s_{1} = t_{0}$ and $s_{n_{s}} = t_{1}$. We provide an analytical form of $\mathfrak{b}$ later in Section [IV](https://arxiv.org/html/2506.10739v1#S4 "IV From STL tasks to time-varying sets: Viability ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach"), from which these assumptions will be clarified. For the time-varying set $\mathcal{B}{(t)}$, we often consider the left limit defined as ${\lim_{\tau\rightarrow^{-}t}{\mathcal{B}{(\tau)}}} = {\{{{\mathbf{x}} \in {\mathbb{X}}}\mid{{\lim_{\tau\rightarrow^{-}t}{{\mathfrak{b}}{({\mathbf{x}},\tau)}}} \geq 0}\}}$, which exists for all $t \in {\lbrack t_{0},t_{1}\rbrack}$, as per piece-wise linearity of the function ${\mathfrak{b}}{( \cdot,t)}$, and we note that in general, ${\lim_{\tau\rightarrow^{-}s_{i}}{\mathcal{B}{(\tau)}}} \neq {\mathcal{B}{(s_{i})}}$ due to the time discontinuity at each $s_{i}$. Moreover, $\mathcal{B}{(t)}$ is convex for every time $t \in {\lbrack t_{0},t_{1}\rbrack}$, by the concavity of ${\mathfrak{b}}{({\mathbf{x}}, \cdot )}$ and convexity of $\mathbb{X}$ \[(https://arxiv.org/html/2506.10739v1#bib.bib34), Sec. 3.1.6\].

A pivotal aspect in our planning framework is the ability to synthesize dynamically feasible trajectories that evolve within a time-varying set of the form ((https://arxiv.org/html/2506.10739v1#S2.E12 "In II-B Viability and forward invariance of set-valued maps ‣ II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")), which we ought to design in order to satisfy a given STL task. The notion of forward-invariance of set-valued maps is thus introduced.

### Definition 1

A time-varying set $\mathcal{B}:{{\lbrack t_{0},t_{1}\rbrack}\rightarrow 2^{\mathbb{X}}}$ is forward invariant w.r.t ((https://arxiv.org/html/2506.10739v1#S2.E1 "In II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")) over $\lbrack t_{0},t_{1}\rbrack$, if for every $\mathbf{x}_{0} \in {\mathcal{B}{(t_{0})}}$, there exists an input signal $\zeta_{u}:{{\lbrack t_{0},t_{1}\rbrack}\rightarrow{\mathbb{U}}}$, with corresponding solution $\zeta_{x}:{{\lbrack t_{0},t_{1}\rbrack}\rightarrow{\mathbb{X}}}$ to ((https://arxiv.org/html/2506.10739v1#S2.E1 "In II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")), such that ${\zeta_{x}{(t_{0})}} = \mathbf{x}_{0}$ and ${{\zeta_{x}{(t)}} \in {\mathcal{B}{(t)}}},{{\forall t} \in {\lbrack t_{0},t_{1}\rbrack}}$.

Due to the switching sequence ${(s_{i})}_{i = 1}^{n_{s}}$ induced by the function $\mathfrak{b}$, an essential precondition for forward invariance of the set $\mathcal{B}{(t)}$ is the notion of viability.

### Definition 2

A time-varying set $\mathcal{B}:{{\lbrack t_{0},t_{1}\rbrack}\rightarrow 2^{\mathbb{X}}}$ is viable if ${\mathcal{B}{(t)}} \neq \varnothing$ and ${{\lim_{\tau\rightarrow^{-}t}{\mathcal{B}{(\tau)}}} \subseteq {\mathcal{B}{(t)}}},{{\forall t} \in {\lbrack t_{0},t_{1}\rbrack}}$.

The notion of viability ensures that a time-varying set $\mathcal{B}{(t)}$ is well behaved at the switching times ${(s_{i})}_{i = 1}^{n_{s}}$ according to the following intuition. If we let $\zeta_{x}:{{\lbrack t_{0},t_{1}\rbrack}\rightarrow{\mathbb{X}}}$ be an absolutely continuous solution to ((https://arxiv.org/html/2506.10739v1#S2.E1 "In II Preliminaries ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")) such that ${\lim_{\tau\rightarrow^{-}s_{i}}{\zeta_{x}{(\tau)}}} \in {\lim_{\tau\rightarrow^{-}s_{i}}{\mathcal{B}{(\tau)}}}$ for any $s_{i}$ in the sequence ${(s_{i})}_{i = 1}^{n_{s}}$, then ${\zeta_{x}{(s_{i})}} \in {\mathcal{B}{(s_{i})}}$ even if ${\lim_{\tau\rightarrow^{-}s_{i}}{\mathcal{B}{(\tau)}}} \neq {\mathcal{B}{(s_{i})}}$ such that $\zeta_{x}$ can not jump outside $\mathcal{B}{(t)}$ at time $s_{i}$ (c.f. \[(https://arxiv.org/html/2506.10739v1#bib.bib33), Def. 2\], \[(https://arxiv.org/html/2506.10739v1#bib.bib32), Sec. ## Conclusion

We introduced a sampling-based planning framework, based on RRT^⋆^, to synthesize trajectories under STL specifications with real-time performance. Namely, our approach leverages suitably constructed time-varying sets, with provable forward invariance guarantees with respect to controllable and input limited linear dynamics, to synthesize trajectories robustly satisfying a given STL task. As a next step, we aim to further expand our framework to nonlinear systems, applying techniques from spline optimization, and to broaden the class of STL specifications that we can consider.

Since ${\mathcal{L}_{{\mathfrak{b}}_{l}^{\varphi}}^{j}{({\mathbf{x}},{\mathbf{u}},t)}} \subseteq {\mathcal{L}_{{\mathfrak{b}}^{\phi}}^{j}{({\mathbf{x}},{\mathbf{u}},t)}}$, as per ((https://arxiv.org/html/2506.10739v1#A0.E68 "In Proof. ‣ -E Proof of Proposition 6 ‣ VIII Conclusion ‣ Sampling-Based Planning Under STL Specifications: A Forward Invariance Approach")), then ${{\min\mathcal{L}_{{\mathfrak{b}}^{\phi}}^{j}}{({\mathbf{x}},{\mathbf{u}},t)}} \leq {{\min\mathcal{L}_{{\mathfrak{b}}_{l}^{\varphi}}^{j}}{({\mathbf{x}},{\mathbf{u}},t)}} < {- {\kappa{({{\mathfrak{b}}^{\phi}{({\mathbf{x}},t)}})}}}$ which is a contradiction, concluding the proof. ∎
