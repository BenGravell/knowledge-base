An Algorithm for the Organization of Information

Topics include Data structures, Binary search trees, Self-balancing trees, AVL trees, Information organization, Logarithmic complexity, Tree rotations.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Introduces a height-balanced binary search tree for organizing information in computer memory. Bounds the tree height logarithmically by requiring the two subtree heights at each node to differ by at most one, and gives a rebalancing insertion procedure that supports logarithmic search and insertion.
