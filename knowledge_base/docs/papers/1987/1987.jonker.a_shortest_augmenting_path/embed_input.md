A Shortest Augmenting Path Algorithm for Dense and Sparse Linear Assignment Problems

Topics include Assignment problem, Shortest augmenting path, Linear assignment, Sparse matrices, Dense matrices, Combinatorial optimization, Network algorithms.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Jonker and Volgenant present a shortest-augmenting-path algorithm for linear assignment problems designed to perform well on both dense and sparse instances. The paper is a practical successor to Hungarian-style methods and became influential through fast assignment implementations.

<!-- chunk {"id": "abstract-0003", "role": "abstract", "section": "Abstract", "weight": 2.0} -->

We develop a shortest augmenting path algorithm for the linear assignment problem. It contains new initialization routines and a special implementation of Dijkstra's shortest path method. For both dense and sparse problems computational experiments show this algorithm to be uniformly faster than the best algorithms from the literature. A Pascal implementation is presented.
