Méthode Générale Pour La Résolution Des Systèmes D'Équations Simultanées

Topics include Gradient descent, Steepest descent, Optimization, Numerical methods, Systems of equations.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Cauchy's classic note is an early source for the method now recognized as gradient descent or steepest descent, proposing iterative progress guided by derivatives for solving simultaneous equations. It is primarily useful as historical context for first-order optimization.
