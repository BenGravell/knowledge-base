The Numerical Solution of A'Q + QA = -C

Topics include Lyapunov equation, Matrix equations, Numerical linear algebra, Canonical forms, Control theory, Stability analysis.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Davison and Man present a numerical approach for solving the continuous-time Lyapunov equation A'Q + QA = -C by exploiting canonical-form transformations built from the system matrix eigenvalues. The paper is an early contribution to computational state-space control, where Lyapunov equations are central to stability, observability, controllability, and quadratic-performance calculations.

<!-- chunk {"id": "abstract-0003", "role": "abstract", "section": "Abstract", "weight": 2.0} -->

The eigenvalues of the system matrix are used to construct a matrix which is a transformation in state space between two most frequently used canonical forms.
