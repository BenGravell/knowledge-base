Dynamic Programming and Stochastic Control

Topics include Dynamic programming, Stochastic control, Sequential decision making, Partial observation, Markov decision process, Infinite horizon.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Develops a unified framework for sequential decision making under uncertainty using dynamic programming. Covers finite and infinite horizon stochastic control, imperfect state information, risk, sufficient statistics, adaptive control, and discounted, undiscounted, and average cost problems.
