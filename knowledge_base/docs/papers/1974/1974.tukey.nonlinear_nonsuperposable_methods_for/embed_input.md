Nonlinear (Nonsuperposable) Methods for Smoothing Data

Topics include Signal filtering, Nonlinear smoothing, Median filtering, Robust smoothing, Outlier removal, Order-statistic filters, Time series, Impulsive noise.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Presents Tukey's early formulation of nonlinear, nonsuperposable smoothing methods for data sequences, helping establish median-style smoothers as robust alternatives to linear averaging when outliers or sharp features are important. The note became a foundational citation for later median filters, rank-order filters, and LULU smoothing theory.
