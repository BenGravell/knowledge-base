Beyond Regression: New Tools for Prediction and Analysis in the Behavioral Sciences

Topics include Backpropagation, Neural networks, Automatic differentiation, Dynamic feedback, Behavioral sciences, Prediction, Nonlinear regression.

Werbos' dissertation is the early source usually credited with formulating backpropagation for training multilayer neural networks through reverse-mode differentiation. It frames the method more broadly as a tool for prediction, sensitivity analysis, and dynamic feedback systems, connecting statistical regression, control, and adaptive computation.

This thesis develops new tools for prediction and analysis beyond ordinary regression, emphasizing dynamic feedback, nonlinear regression, sensitivity analysis, and the efficient computation of derivatives for adaptive systems.
