Fast Approximate Nearest-Neighbor Search with k-Nearest Neighbor Graph

Topics include Approximate nearest neighbors, k-nearest neighbor graph, Graph search, Hill climbing, High-dimensional search, Information retrieval, Computer vision.

Introduces Graph Nearest Neighbor Search, which builds a k-nearest-neighbor graph offline and answers queries by greedy hill-climbing from random graph nodes. The paper provides theoretical accuracy and complexity guarantees and anticipates later graph-navigation approaches to approximate nearest-neighbor search.

We introduce a new nearest neighbor search algorithm. The algorithm builds a nearest neighbor graph in an offline phase and when queried with a new point, performs hill-climbing starting from a randomly sampled node of the graph. We provide theoretical guarantees for the accuracy and the computational complexity and empirically show the effectiveness of this algorithm.
