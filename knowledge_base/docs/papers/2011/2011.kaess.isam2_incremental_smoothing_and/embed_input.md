iSAM2: Incremental Smoothing and Mapping Using the Bayes Tree

Topics include Simultaneous localization and mapping, Incremental smoothing and mapping, Bayes tree, Factor graphs, Sparse nonlinear optimization, Incremental variable reordering, Fluid relinearization, Probabilistic inference, iSAM2.

Turns the Bayes tree into the iSAM2 algorithm, a fully incremental nonlinear least-squares solver for SLAM and related factor-graph problems. Its key engineering contribution is local graph editing with incremental reordering and selective relinearization, avoiding the periodic full batch steps needed by earlier iSAM.

We present a novel data structure, the Bayes tree, that provides an algorithmic foundation enabling a better understanding of existing graphical model inference algorithms and their connection to sparse matrix factorization methods. Similar to a clique tree, a Bayes tree encodes a factored probability density, but unlike the clique tree it is directed and maps more naturally to the square root information matrix of the simultaneous localization and mapping (SLAM) problem. In this paper, we highlight three insights provided by our new data structure. First, the Bayes tree provides a better understanding of the matrix factorization in terms of probability densities. Second, we show how the fairly abstract updates to a matrix factorization translate to a simple editing of the Bayes tree and its conditional densities. Third, we apply the Bayes tree to obtain a completely novel algorithm for sparse nonlinear incremental optimization, named iSAM2, which achieves improvements in efficiency through incremental variable re-ordering and fluid relinearization, eliminating the need for periodic batch steps.
