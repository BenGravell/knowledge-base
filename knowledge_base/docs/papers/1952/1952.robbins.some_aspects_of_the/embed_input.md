Some Aspects of the Sequential Design of Experiments

Topics include Sequential experiments, Multi-armed bandits, Adaptive sampling, Exploration and exploitation, Statistical decision theory.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Develops sequential experiment designs in which sampling choices depend on previous observations. Introduces the population-selection problem underlying multi-armed bandits and allocation strategies that balance learning about alternatives with selecting high-reward populations.
