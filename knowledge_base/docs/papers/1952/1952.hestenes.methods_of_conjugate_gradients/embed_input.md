Methods of Conjugate Gradients for Solving Linear Systems

Topics include Conjugate gradient, Linear systems, Iterative methods, Krylov subspace methods, Numerical linear algebra, Orthogonal polynomials, Continued fractions.

<!-- chunk {"id": "summary-0002", "role": "summary", "section": "Summary", "weight": 2.0} -->

Hestenes and Stiefel introduce the conjugate gradient method for solving linear systems, especially symmetric positive-definite systems, using mutually conjugate directions. The paper explains finite-step exactness in exact arithmetic, connects the method to Gaussian elimination and orthogonal polynomial theory, and became a cornerstone of large-scale numerical linear algebra.

<!-- chunk {"id": "abstract-0003", "role": "abstract", "section": "Abstract", "weight": 2.0} -->

An iterative algorithm is given for solving a system Ax = k of n linear equations in n unknowns. The solution is given in n steps. It is shown that this method is a special case of a very general method which also includes Gaussian elimination. These general algorithms are essentially algorithms for finding an n dimensional ellipsoid. Connections are made with the theory of orthogonal polynomials and continued fractions.
